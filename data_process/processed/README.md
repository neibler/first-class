# 가공 데이터·변수 안내

- 가격 계산 기준: `adj_close` 수정종가
- 거래일 기준: SPY의 미국 ETF 거래일, 전체 2,198일
- 정규화 입력: [splits/](../splits/README.md), 이 폴더의 수익률·통합 데이터는 비정규화 값

**파일명: `etf_features.parquet`**

- 기간: 2018-01-02~2026-09-30
- 데이터 형태: 세로형(Long), 날짜 × ETF 15개
- 행 × 컬럼: **32,970 × 8**
- 사용 컬럼: `date`, `ticker`, `adj_close`, `log_return`, `rsi_14`, `macd`, `macd_signal`, `macd_hist`
- 계산·활용 목적: 수정종가·수익률·기술적 지표 보관, 통합 입력 생성
- 생성 코드: `src/preprocessing/04_calculate_features.py`

**파일명: `log_returns.parquet`**

- 기간: 2018-01-02~2026-09-30
- 데이터 형태: 세로형(Long), 날짜 × ETF 15개
- 행 × 컬럼: **32,970 × 3**
- 사용 컬럼: `date`, `ticker`, `log_return`
- 계산·활용 목적: ETF별 비정규화 로그수익률 보존, 보상·성과 계산용 수익률 원천
- 생성 코드: `src/preprocessing/04_calculate_features.py`
- 주의사항: ETF별 첫 거래일 수익률 NaN 유지

**ETF 파생변수**

| 변수 | 의미·계산 방식 |
|---|---|
| `log_return` | 전 거래일 대비 수정종가의 자연로그 변화율, `ln(오늘 가격 / 전 거래일 가격)`, ×100 미적용 |
| `rsi_14` | 최근 상승·하락 강도, `100 × 평균상승폭 / (평균상승폭 + 평균하락폭)`; 최초 14개 변동의 단순평균 이후 Wilder 평활화, 평활계수 1/14; 변동 없는 구간 50 |
| `macd` | 수정종가의 12거래일 지수이동평균 − 26거래일 지수이동평균 |
| `macd_signal` | 유효한 MACD의 9거래일 지수이동평균 |
| `macd_hist` | `macd − macd_signal` |

지수이동평균 기준: 재귀 계산(`adjust=False`), 각 기간만큼 자료 확보 후 첫 값 생성

**파일명: `macro_features.parquet`**

- 기간: 관측일 2017-01-01~2026-09-30; PMI 원본 발표일 2017-01-04~2026-09-01
- 데이터 형태: 세로형(Long), 변수·관측일·Vintage 또는 계산 상태별 데이터
- 행 × 컬럼: **21,351 × 17**
- 사용 컬럼: [원본 8개 컬럼](../raw/README.md) + 아래 계산 추적용 9개 컬럼
- 계산·활용 목적: 같은 시점의 유효한 원본 버전으로 PCE·달러 변화율·금리차 계산, 05번 결합용 상태 보관
- 생성 코드: `src/preprocessing/04_calculate_features.py`

| 추가 컬럼 | 의미 |
|---|---|
| `calculation_date` | 파생변수 계산 상태의 시작일 |

| `base_observation_date`, `base_value`, `base_realtime_start`, `base_realtime_end` | 비교 대상 관측일·값·원본 유효기간 |
| `lag_reference_date` | 비교 기준 날짜, 전월·전년 동월·20거래일 전 기준 |

- 변환 없는 원본 변수 9개: 값·날짜 그대로 보관, 계산 추적용 컬럼은 결측
- 파생변수의 `realtime_start`·`realtime_end`: 계산 결과 상태의 유효기간
- 입력·비교 값의 유효기간: `input_realtime_start`·`input_realtime_end`, `base_realtime_start`·`base_realtime_end`로 별도 보관

**최종 거시경제 변수 13개**

| 변수명 | 의미 | 단위·변환 방식 |
|---|---|---|
| `core_pce_yoy` | 근원 개인소비지출 물가 상승률 | 전년 동월 대비 %, `(현재 / 12개월 전 − 1) × 100` |
| `real_pce_mom` | 실질 개인소비지출 증가율 | 전월 대비 %, `(현재 / 전월 − 1) × 100` |
| `unemp` | 미국 실업률 | % |
| `ism_pmi` | ISM 제조업 구매관리자지수 | 지수 수준 |
| `effr` | 실효연방기금금리 | % |
| `ust_2y` | 미국 2년물 국채금리 | % |
| `ust_10y` | 미국 10년물 국채금리 | % |
| `ust_30y` | 미국 30년물 국채금리 | % |
| `tips_10y` | 미국 10년물 물가연동국채 실질금리 | % |
| `vix` | VIX 변동성지수 | 지수 수준 |
| `usd_ret_20d` | 광의 달러지수의 20거래일 변화율 | 자연로그 변화율, ×100 미적용 |
| `wti` | WTI 현물 유가 | 달러/배럴, 원가격 |
| `yield_spread` | 10년물 − 2년물 국채금리 | %p, 동일 관측일·동일 시점의 두 금리 차이 |

달러 변화율 기준: 그때 알려진 최신 달러 관측일에서 SPY 20거래일 전 날짜 산정, 해당 날짜 이하의 최신 유효 비교값 선택, 두 값 모두 같은 Vintage 기준

**파일명: `features_unscaled.parquet`**

- 기간: 2018-01-02~2026-09-30
- 데이터 형태: 세로형(Long), 날짜 × ETF 15개, 같은 날짜의 거시지표 동일 값
- 행 × 컬럼: **32,970 × 21**
- 사용 컬럼: `etf_features.parquet`의 8개 컬럼 + 거시경제 변수 13개
- 계산·활용 목적: 정규화 이전 ETF·거시 통합 입력, Window 시작 전 관측 이력 원천
- 생성 코드: `src/preprocessing/05_merge_data.py`

| 결합 대상 | 시점 기준 |
|---|---|
| 기본 기준 | 미국 동부시간 16:00까지의 정보, 서머타임 반영, ETF 기술적 지표 날짜 이동 없음; VIX·WTI는 아래 근사 예외 |
| PCE·실업률·EFFR | ALFRED 날짜 기준, 별도의 일괄 하루 지연 없음 |
| 국채금리·TIPS·금리차 | ALFRED 날짜와 H.15 발표 일정 비교, 두 금리가 모두 알려진 시각 반영 |
| 달러지수 | ALFRED 날짜와 H.10 주간 발표 일정 비교, 16:15 발표는 다음 ETF 거래일부터 반영 |
| PMI | 확인된 미국 발표일 10:00 기준, 117건 대조·41건 날짜 보정, 원본 파일 보존 |
| VIX·WTI | 최초 유효 가격을 관측일의 당일 가격으로 근사; 이후 수정·철회는 원래 Vintage일 이후 반영 |

- Vintage 선택: 이용 가능한 유효 버전 중 가장 최근 관측일 선택, 오래된 관측값의 수정으로 최신 관측값 대체 금지
- 결측 처리: 다른 이전 관측값이 아직 유효한 경우에만 유지, 만료·철회된 버전 재사용 및 미래 값 채우기 금지
- 시점 한계: H.15·H.10은 공식 일정 기반 시각 복원, 과거 개별 장중 발표 기록 부재
- VIX 시점 근사: 일별 최종값에 16:15까지 정보 포함 가능, 엄밀한 16:00 기준 자료와 차이
- WTI 시점 근사: EIA 사후 집계가격의 관측일 시장가격 근사, 엄밀한 당시 공개가격 자료와 차이
- 음수 WTI 보존: 2020-04-20 **−36.98**, 로그수익률 변환 미적용
- 초기 결측 보존: 수익률·RSI·MACD 준비 구간, PCE 전년 비교 자료 부족 구간, 달러지수 최초 공개 전 구간
- 결측 없는 입력 시작일: **2019-02-05**, 이후 19개 입력변수 결측 없음
