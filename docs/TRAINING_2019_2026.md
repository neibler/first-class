# 2019~2026 입력 학습 안내

## 입력 및 정책

- source: data_process/processed/features_unscaled.parquet + runtime/data/news/raw/news_risk_nyt_2019_2026.csv
- prepared: runtime/data/prepared/d1e0a7c0b46d/{market,news}.parquet
- 공통 유효 기간: 2019-02-05 ~ 2026-09-30, 1,924일, 28,860행, ETF 15개, macro 13개.
- 3% 미만 제거 후 상위 최대 7개 유지, 합 1로 정규화. 월별/위험 0.7/거리 0.10, MDD > 0.15 현금 전환.
- seeds 17, 22, 43; 각 모델·seed·window당 100,000 step; reward return_mdd.
- 과거 E 공유 패키지와 결과는 수정하지 않음. 새 결과는 TOP7_NEWS2019_WF 날짜 실행 이름으로 구분.

## 분할

config/multi_model.json의 training_windows는 다음 학습/평가 구간을 명시한다. 자동 날짜 계산과 test_fraction 대신 이 구간을 적용한다.

| 저장 window | 학습 | 평가 |
|---|---|---|
| window_0 | 2019-02-05 ~ 2022-12-30 | 2023-01-03 ~ 2023-12-29 |
| window_1 | 2020-01-02 ~ 2023-12-29 | 2024-01-02 ~ 2024-12-31 |
| window_2 | 2021-01-04 ~ 2024-12-31 | 2025-01-02 ~ 2025-12-31 |

팀 전처리 window_1/2/3과 투자 AI 저장 window_0/1/2는 같은 순서다. 첫 구간은 결측 제거로 2019년 2월부터 시작한다. scaler는 각 학습 구간만 사용한다. 팀의 미리 정규화된 features_refit을 다시 정규화하지 않는다.

2026년은 위 비교에서 제외한다. 모델·설정 선정 후 config/final_2026.json으로 2022-01-03~2025-12-31 학습, 2026-01-02~2026-09-30 최종 평가를 별도 실행한다. 2026 성과로 반복 튜닝하면 최종 독립 평가로 볼 수 없다.

## 실행

PowerShell 프로젝트 루트에서 실행. 아래는 4모델 x 3seed x 3window = 36회 학습이며 자동 평가를 포함한다. 학습만 하면 evaluation/SHAP이 자동 생성되는 것은 아니다.

```powershell
$env:INVESTMENT_AI_HOME = "$PWD/runtime"
$runId = "TOP7_NEWS2019_WF_" + (Get-Date -Format "yyyyMMdd_HHmmss")
foreach ($model in @("ppo", "recurrent_ppo", "sac", "td3")) {
    .\.venv312\Scripts\python.exe local_run.py train --config config/multi_model.json --model $model --run-id $runId
    if ($LASTEXITCODE -ne 0) { throw "$model training failed" }
    foreach ($window in @("window_0", "window_1", "window_2")) {
        foreach ($seed in @(17, 22, 43)) {
            $bundle = "runtime/models/$model/$runId/$window/${model}_return_mdd_seed$seed"
            .\.venv312\Scripts\python.exe local_run.py evaluate --bundle $bundle
            if ($LASTEXITCODE -ne 0) { throw "$model evaluation failed" }
        }
    }
}
```

사전 확인: local_run.py train --config config/multi_model.json --model ppo --dry-run

SHAP은 선택한 새 bundle에 --bundle 옵션으로 계산한다. --all-shared는 여전히 이전 E seed42 공유 모델을 가리키므로 새 학습의 SHAP 계산에 사용하지 않는다. 여러 seed/window 패키징은 현재 4개 단일 bundle 공유 스크립트가 자동 선정하지 않으므로 평가 후 명시적으로 선택해야 한다.

## 제한 및 재현

입력 날짜/종목 누락, 유한 수치, 가격·로그수익률 정합성 검증을 통과했다. upstream VIX/WTI 가용일은 근사 정책을 포함하여 엄밀한 point-in-time 무누출 보장은 별도 검토 대상이다. 새 뉴스에는 evidence/evidence_url이 없지만 학습용 6개 필드는 보존한다.

기존 체크포인트를 resume하면 기존 데이터·정책 설정을 사용하므로 이번 실험은 새 run으로 시작한다. 새 설정 파일을 다시 만들거나 입력 준비를 재실행할 때 final_2026 및 no_risk 설정의 입력 경로도 확인한다.
