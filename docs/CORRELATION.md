# 자산 관계 분석

이 기능은 모델의 판단 설명(SHAP), 뉴스 리서치와 독립적이다. 모델 파일이나 학습 중인
체크포인트를 읽지 않으며 학습·입력·전처리 파일을 변경하지 않는다.

## 입력과 계산

기존 `read_config`와 `load_data`로 `config/multi_model.json`이 지정하는 실제 입력을 읽는다.
입력은 runtime 기준 상대 경로를 따르며 임의의 더미 데이터로 대체하지 않는다.
현재 설치 입력 기간은 2019-02-05~2026-09-30이다.
`python scripts/install_training_inputs.py`로 최신 config가 참조하는 검증 ZIP을 설치한다. 화면 기준일은 시스템 오늘이 아닌
마지막 데이터 날짜다. 계산은 종목 간 공통 거래일의 Pearson 상관계수다.

| 대상 | 변환 |
|---|---|
| 15개 ETF | 기존 일별 log_return. 가격 수준을 쓰지 않는다. |
| UST 2Y/10Y/30Y, TIPS 10Y | 전처리된 금리 수준의 일별 diff |
| Yield Spread | 전처리된 장단기 금리 차이의 일별 diff |
| VIX | 일별 diff |
| WTI | 현재/이전 가격 - 1, 양쪽 값이 양수일 때만 계산 |

기존 전처리는 거시지표를 이용 가능 시점으로 정렬한다. 이 정렬을 유지하므로 금리·VIX·WTI
변화에는 발표 지연과 수정 이력이 반영될 수 있다. 지표의 원래 관측일 기준 동시 관계와
같다고 단정하지 않는다. 전처리된 값을 다시 앞당기거나 미래 값을 사용하지 않는다.
`as_of` 이전 자료만 사용하며 결측을 보간하거나 forward/backward fill하지 않는다.

## 제외 항목

- Core PCE YoY, Real PCE MoM, 실업률, ISM PMI: 월별/저빈도 지표의 반복 수준을
  일별 ETF 수익률과 상관 분석하지 않는다.
- EFFR: 정책 변경 중심으로 장기간 일정한 구간이 있어 초기 일별 분석에서 제외한다.
- usd_ret_20d: 현재 준비된 입력은 20거래일 로그수익률이다. 이를 일별 수익률이나
  그 대용값으로 변환하지 않는다. `data_process/raw/macro_observations.parquet`의
  broad_usd 수정 이력 원본은 있으나, 일별 기준 관측·발표 시점 정렬을 별도로 검증해야 한다.
  현재 전처리의 20일 값에 단순 차분을 취해 USD 일별 수익률로 표시하지 않는다.
- 뉴스 위험·RSI·MACD·현재 비중: 이 화면의 시장 관계 분석 대상이 아니다.
- 미등록 macro는 변환 의미 검증 전까지 제외하고 상세보기에서 이유를 표시한다.

## 설정

`backend/performance/correlation.py`의 `CorrelationConfig`:
기본 window=60, 선택 가능 window=(20,60,120,252), 기본 Top K=5,
강도 구간 경계=(0.2,0.4,0.6,0.8).
프론트의 분석 기간 선택에서도 20/60/120/252를 선택할 수 있다.

매 구간에 window개 유효 쌍이 모두 있어야 계산한다. 유효 관측이 부족하거나
분산이 사실상 0(std<=1e-12)이면 결과에서 제외한다. NaN을 0의 상관계수로 표시하지 않는다.
자기 자신은 제외하고 절댓값 내림차순, 동률은 이름 순으로 정렬한다.

Rolling 그래프는 각 거래일 직전 window개 관측으로 계산한다. 최근 관계 변화 설명은
현재 구간과 바로 이전의 겹치지 않는 window개 구간을 비교한다. 둘 다 유효할 때만
강화·약화·방향 전환 문구를 생성한다. 통계적 유의성이나 예측력을 뜻하지 않는다.

## API와 UI

`GET /performance/correlation/TLT?window=60&top_k=5`
선택적으로 `as_of=2025-12-31` 사용 가능. 날짜는 YYYY-MM-DD.

- relationships: Top K의 값·변환·설명·관계 변화
- all_relationships: 선택 ETF의 전체 유효 관계(상세보기)
- rolling: Top K의 전체 롤링 시계열, 계산 불가 값은 null
- date/window_start: 실제 분석 종료/시작일
- excluded_features/unavailable_relationships: 제외 사유
- status: ok 또는 insufficient_data

잘못된 window/날짜는 422, 미지원 ETF는 404, 실제 입력 설치/검증 실패는 503.
관측 부족은 200 응답과 insufficient_data 안내로 처리한다.

왼쪽 메뉴의 **자산 관계 분석**에서 ETF와 기간을 선택한다. 기본 화면은 Top 5,
항목 선택은 rolling 그래프와 현재 계수, 겹치지 않는 이전 구간 비교를 보여준다.
그래프는 기존 Altair를 사용하며 -1~+1 축과 0 기준선을 표시한다. 추가 패키지는 없다.
전체 관계와 변환·제외 이유는 접힌 상세보기 안에 제공한다. 전체 자산 matrix는 기본 화면에 없다.
SHAP 화면에서는 해당 메뉴의 위치만 안내하며 두 값을 결합하거나 인과관계로 해석하지 않는다.

API 서버를 재시작하고 브라우저를 새로고침하면 메뉴를 사용할 수 있다.
학습 터미널은 재시작할 필요가 없다.

## 시작점 100 비교 그래프

`backend/performance/correlation_visuals.py`는 통계와 분리된 시각화 전용 모듈이다.
`normalize_series_to_100`은 첫 유효 양수 값을 기준으로 `value/base*100`을 계산한다.
0·음수 기준값은 방향 반전/나눗셈 문제를 피하기 위해 거부한다. NaN/inf는 유효값으로
쓰지 않는다. `normalize_pair`는 공통 유효 날짜를 먼저 맞춘 뒤 두 시작점을 동시에
100으로 맞춘다. 데이터 부족은 비교 그래프만 unavailable로 표시한다.

ETF는 이미 검증된 일별 로그수익률로 상대 가격을 재구성한다. 기존 전처리의 ETF
로그수익률은 수정종가로 계산되어 있다. 별도의 raw 가격 파일을 섞거나 다운로드하지 않는다.
그래프는 분석 window의 첫 날짜 종가를 100으로 두고 이후 수익률을 누적한다.
따라서 60개 날짜를 표시할 때 첫 종가 이후의 변동은 59개다. 상관계수에는 기존대로
첫 날짜의 전일 대비 수익률까지 60개 관측이 사용된다. 그래프의 날짜 범위는 동일하다.
원본 달러 가격을 표시하지 않으며, 재구성 상대 가격임을 UI에 명시한다.

금리·VIX·WTI는 변환 전 정렬된 수준값을 사용한다. 상관계수 계산용 diff/return을
가격처럼 누적하지 않는다. 금리·시장지표는 '정규화 시장값 변화'로 표시한다.
시장값 시작점이 0·음수인 경우 안내를 표시하고 기존 통계·롤링 그래프는 유지한다.
음의 상관관계에서도 어느 시계열도 -1을 곱해 반전하지 않는다.
공통 유효 날짜가 window보다 적으면 실제 시작일·관측 수를 명시한다.

API 응답 `comparisons`에 Top K별 status/kind/records/source_note를 추가했다.
기존 relationships/rolling 계산에는 정규화 값을 전달하지 않는다.

UI 순서: 선택 관계 → 현재/이전/변화 계수 → 정규화 비교 그래프 →
window거래일 Rolling Correlation → 자연어 설명.
비교 그래프 tooltip은 날짜와 양쪽의 '시작=100' 값을 함께 표시하고 색상 범례를 제공한다.
롤링 그래프가 여러 해인 이유는 각 날짜의 직전 window개 관측을 반복 계산하기 때문임을 안내한다.

과거 구간 60거래일 예시(2025-10-07~2025-12-31):
- SPY–QQQ: r=+0.9613, SPY 100→102.2141, QQQ 100→101.7521.
- SPY–VIX 변화: r=-0.8440, SPY 100→102.2141, VIX 수준 100→86.7169.
끝점 수익률만으로 일별 상관관계를 계산하는 것은 아니다.
