# 최대 보유 ETF 수

새 학습 설정의 `max_holdings` 기본값은 7입니다. 후보 자산과 action 차원은 기존 15개를 유지합니다.

처리 순서: softmax → 원래 목표 비중이 3% 미만이면 제거 → 남은 비중 상위 7개 유지 → 합 1로 재정규화 → 기존 리밸런싱 판단.

동률이면 설정의 자산 순서를 따릅니다. 기준을 통과한 자산이 7개보다 적으면 그대로 유지하며, 모두 제거되는 경우 원래 최대 비중 자산 하나를 유지합니다. 실제 거래는 기존 월별·뉴스 위험·포트폴리오 거리 조건을 따르고, MDD 안전장치는 현금 100%로 우선 전환합니다. 거래 없는 날에는 보유 수량을 유지합니다.

`config/multi_model.json` 등의 `max_holdings`를 양의 정수로 변경할 수 있습니다. null 또는 설정 누락은 제한 없음이며, 기존 저장 모델의 재현성을 위해 유지합니다. 새 조건의 성과는 별도 run_id로 재학습·평가한 뒤 SHAP을 계산해야 합니다. 기존 E 모델 및 공유 패키지는 자동 변경하지 않습니다.

학습 환경, 추론, SHAP 출력 변환에 동일한 함수를 사용합니다. 동일비중 벤치마크는 비교 목적상 기존 15개 자산 정책을 유지합니다. 이미 7개 초과를 보유한 외부 상태는 다음 실제 리밸런싱 때 제한이 적용됩니다.
